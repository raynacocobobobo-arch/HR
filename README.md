# HRPM 视频部运营系统 · 界面 Demo

这是视频部 HRPM 的静态交互样稿，用于确认页面结构、业务对象和操作逻辑。
所有人物、项目、金额和排期均为模拟数据，不连接正式数据库。

## 在线预览

<https://raynacocobobobo-arch.github.io/HR/>

## 页面

- 工作台：异常优先的经营与执行总览
- 项目：七阶段门、任务与成本预测
- 人员：技能、费率、负荷与可用时间
- 档期：Timefold 调整前后对比与整套确认
- 工时：计划工时、实际工时与偏差
- 成本：计划、实际、完工预测三条线
- 报表：项目健康、产能与经营复盘
- 模板与设置：项目模板、排期规则和经验建议

右侧“功能与原理”会随页面变化，解释该页面解决的问题、数据来源、计算方法和人工确认边界。

## 本地查看

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8766/>。

## 浏览器契约测试

测试需要本机 Python Playwright 与 Google Chrome：

```bash
python3 -m unittest discover -s tests -v
```
